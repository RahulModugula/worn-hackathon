Honest positioning

A documentation aid. Not a diagnostic.

FDA

The nurse decides. The wound feature drafts a note for clinician review; it does not measure, stage or diagnose. An FDA determination comes before any analytics.

HIPAA and privacy

Synthetic data only today. Production needs a BAA, encryption, MDM and unit sign-off. No audio stored; the server holds up to 20 photos in memory (not on disk). Audio goes to Deepgram and photos to Gemini only if keys are set; no BAA in the demo.

The allergy alert shows the chart's own allergy list next to the scanned patient's meds. It does not override or block. We claim no clearance, no real patients and no hospital partners.
